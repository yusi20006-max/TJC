# TJC

TJC (Termux Jules CLI) is a shell-based CLI foundation for Google Jules API workflows on Termux and Linux.

## Current status
Bootstrap foundation only. API, auth, sessions, repositories, and workflows are added in later issues.

## Commands
- `tjc help`
- `tjc version`
